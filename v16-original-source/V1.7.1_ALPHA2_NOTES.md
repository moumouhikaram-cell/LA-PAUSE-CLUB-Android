# LA PAUSE OS Android v1.7.1-alpha2 — A2 Venue + Resources

## Scope
First real normalized SQLite domain migration. This release does **not** remove or replace the legacy operational state.

## Added
- Core DB schema v2, non-destructive migration from v1.
- `venue_profile` normalized domain.
- Universal `resources` registry with tombstone support and capabilities.
- `domain_authority` ledger.
- `migration_checkpoints` per source revision.
- Dual-write from the current operational JSON into normalized Venue + Resources.
- A2 status panel in Mode & Synchronisation.

## Authority state
- `VENUE`: `SQLITE_DUAL_WRITE / PARITY_PROVING`
- `RESOURCES`: `SQLITE_DUAL_WRITE / PARITY_PROVING`
- Legacy JSON stays the read/recovery source in alpha2.
- No financial/session authority migration in this release.

## Compatibility
- Same package: `com.lapauseclub.manager`
- Permanent signing lineage unchanged.
- Frozen El Hajeb rates remain 22 / 28 / 45 MAD.
- Existing Android features and data remain additive and preserved.

## Real-device acceptance
After installing over v1.7.0-alpha1:
1. Existing data and features remain visible.
2. Mode & Synchronisation shows DB v2.
3. Venue is LA PAUSE CLUB / El Hajeb.
4. Current venue resource registry shows 7 resources: 6 console + 1 SIM.
5. VENUE and RESOURCES report `SQLITE_DUAL_WRITE`.
6. Migration reports `PARITY_PROVING`.
7. No uninstall or data reset is required.
