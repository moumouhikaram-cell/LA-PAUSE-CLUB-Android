# LA PAUSE OS — UI FROZEN REFERENCE V1

Status: FROZEN

This document freezes the five validated product templates as the visual baseline for Android.

## Screens
1. Dashboard premium photo-first
2. Consoles & Stations photo grid
3. Vue d'ensemble & gestion globale
4. Billards & Snooker product detail
5. Configuration rapide / onboarding wizard

## Non-negotiable rules
- Dark premium navy/black foundation with purple neon accents.
- Real/premium equipment photography by default, available offline.
- Dashboard opens as a real venue, not a technical cockpit.
- Station cards always expose visual status, players, timer, activity/game and payment/session state.
- Billiard, snooker, PC and other timed resources are first-class operational resources when a valid RatePlan exists.
- French is the default UI language; no English residue in visible status labels.
- Active timers use heavy type and high-contrast backing.
- Queue uses visual equipment chips/icons.
- Equipment action buttons align on the right edge.
- Average durations render as `1h 42m`, never ambiguous `01:42`.
- Setup quantities use large central numerals.
- Marketing reassurance footer is shown during onboarding/trial only, not daily licensed operation.
- Tablet/mobile uses bottom navigation; wider desktop/web may use sidebar and hide redundant bottom navigation.
- Existing operational data and core features must never be deleted to satisfy the visual redesign.

## Change control
Any future UI change that materially alters these screens requires explicit product approval. New features must integrate into this visual system rather than replacing it with generic cards.
